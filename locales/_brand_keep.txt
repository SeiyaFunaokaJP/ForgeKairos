# What keeps upstream's name "Zed" when `cargo run -p i18n_tool -- brand --write` renames the
# application to the product's own name in locales/en/_brand.po and in the translations.
#
# One line per item, four tab-separated fields: kind, reason, context (`-` for none), text.
# The text is written with the escapes of a PO file (\n, \t, \", \\).
#
# Kinds:
#   phrase       text that stays wherever it appears, in any language
#   message      a message (msgctxt and msgid; the action name in _action_docs.po) whose
#                every mention of Zed stays
#   translation  a message whose English does not name the application but whose
#                translations do: the translations are renamed (reason `application`)
# Reasons:
#   service      one of Zed's online services, its account, plans or support
#   fact         a statement about upstream Zed, or a link to its own pages
#   identifier   a value that is stored or typed
#   application  this application (only for `translation`)
