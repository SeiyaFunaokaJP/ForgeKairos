# ForgeKairos artwork

These files are the original ForgeKairos logo artwork, created by the author of this
fork (SeiyaFunaokaJP). They are not derived from Zed's logos.

| File | Contents |
|---|---|
| `ForgeKairos-mark-color.svg` | The color mark (blue-to-violet gradient, viewBox 286 x 304). Source of the app icons. |
| `ForgeKairos-mark-color-1024.png` | The color mark rendered at 1024 x 1024, for checking renders against. |
| `ForgeKairos-mark.svg` | The single-color mark (`currentColor`). Source of the in-app logo. |
| `ForgeKairos-16px.svg` | The mark simplified for 16 px (`currentColor`). Source of the 16 x 16 icons and the 16 / 24 / 32 px icon frames. |
| `ForgeKairos-monochrome.svg` | The full logo (mark and wordmark), single color. |
| `ForgeKairos-full-color.png` | The full logo in color. |

The app icons (`crates/zed/resources/app-icon*.png`, `crates/zed/resources/windows/app-icon*.ico`)
and the in-app logos and icons that show the mark (`assets/images/zed_logo.svg`,
`assets/images/zed_x_copilot.svg`, `assets/icons/forge_kairos.svg`, `assets/icons/zed_agent.svg`,
`assets/icons/zed_predict*.svg`) are generated from these files. After changing the artwork, run:

```
cargo xtask brand-icons
```

`cargo test -p xtask` fails while the generated files are out of date.
`crates/zed/resources/Document.icns` is not generated by this task; it needs macOS `iconutil`.
