# 表示言語と翻訳

[English](../language.md)

ForgeKairos は選んだ言語で UI を表示する。英語と日本語を同梱している。ソースの UI の文字列は英語で、
訳はリポジトリの `locales/` にある gettext の PO ファイルである。

## 言語の選び方

設定 → 全般 → 表示言語 で選ぶか、`settings.json` の `ui_language` に書く。

```json
{ "ui_language": "ja" }
```

| 値 | 意味 |
|---|---|
| `"system"` (既定) | OS の優先言語に従う。その言語の訳が無ければ英語。 |
| `"en"` | 英語 (訳を使わない)。 |
| `"ja"`、`"pt-BR"` などの BCP 47 タグ | その言語。 |

メニュー、設定、コマンドパレットはすぐに切り替わる。タブの題名など一部の文字列は再起動後に切り替わる。

## 訳される範囲

- メニュー、設定ウィンドウ、コマンドパレット、各パネルの文字列。
- コマンドパレットの項目は、訳した名前でも英語の名前でも検索できる。
- アクションの説明 (キーマップエディター、キーマップと設定ファイルのホバーに出る) と、設定ファイルの
  JSON スキーマの説明。
- 同梱のスニペット (Markdown で出す Mermaid の図など) は言語ごとに別の版を持つ。

言語モデルに送る文字列 (ツールの説明、システムプロンプト、ツールの結果) は英語のままで、表示言語によって
モデルへの指示は変わらない。ログのメッセージも訳さない。

## 言語の代替

訳が無いときは、詳しいタグから基本の言語、英語の順に代わりを探す: `pt-BR` → `pt` → 英語。
訳が無い・空・`#, fuzzy` の付いたメッセージは、次の言語で表示する。

## 再ビルドせずに訳を試す・足す

PO ファイルを `<設定フォルダー>/locales/<タグ>/` に置く。設定フォルダーは次のとおり。

| OS | 設定フォルダー |
|---|---|
| Windows | `%APPDATA%\ForgeKairos` |
| Linux | `$XDG_CONFIG_HOME/forgekairos` (設定していなければ `~/.config/forgekairos`) |
| macOS | `~/.config/forgekairos` |

ここに置いた訳は同梱の訳をメッセージ単位で上書きし、同梱していない言語のフォルダーを置けばその言語を
足せる。ファイルはその言語に切り替えたときに読むので、編集したら再起動する。ファイルの誤りは通知とログに
出し、読めた訳は使う。

## リモート

SSH・WSL・Docker のリモートでは、リモートのサーバーが書く文字列 (一部の git のエラー、ターミナルの通知など)
を、サーバーに組み込んだ訳で、接続時に送った言語に訳す。設定フォルダーに置いたファイルはサーバーには
届かない。サーバーは接続しているすべてのクライアントに 1 つの言語を使う (最後に接続したクライアントの言語)。
