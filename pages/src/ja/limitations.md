# 既知の制限

[English](../limitations.md)

## プラットフォーム

- ForgeKairos は Windows で開発し、確かめている。macOS と Linux のパッケージは作っても確かめてもいない。
- 内蔵ブラウザーのパネルは Microsoft Edge WebView2 を使い、Windows でだけ動く。
- 同梱のリモートサーバーは Linux x86_64 のホスト用である。
- Windows 11 では、**ForgeKairos で開く** が「その他のオプションを確認」の下にだけ出ることがある。
- コラボレーション (通話と画面共有) は含まない。

## 外部通信の統制

- エージェントと MCP サーバーに渡すプロキシは、プロキシの環境変数を読むプログラムにだけ効く。
- 許可リストはエディター自身の道具 (言語サーバー、拡張機能、更新、Git) を制限せず、既定では内蔵ブラウザーも
  制限しない。
- サンドボックスの外では、エージェントの通信はプロキシの設定に従う範囲でしか制限できない。

## 翻訳

- 言語モデルに送る文字列とログのメッセージは英語のまま。
- タブの題名など一部の表示は、再起動しないと言語が切り替わらない。
- リモートサーバーは、接続しているすべてのクライアントに 1 つの表示言語を使う。

## C と C++

- シンボル索引は名前で一致させるので、同じ名前の無関係なシンボルが結果に出ることがある。索引からの結果には
  「名前一致」の印を付ける。
- 言語サーバーを再起動した後、誰も開いていないファイルの診断は消えたままになる。ファイルを 1 つも開いて
  いない状態の「すべてのサーバーを再起動」では、サーバーは止まったままになる。
- `clangd.index_mode` が `"light"` のときは、参照、呼び出し階層、名前の変更は開いたファイルだけが対象。

## リモート開発

- 切断をまたいで生きるターミナルは、Windows 以外の SSH のホストでだけ動き、タスクとエージェントのシェルには
  使わない。
- Linux でポーリングで見ているフォルダーの外部の変化は、数秒遅れて見える。

## Markdown、Mermaid、CSV

- 文字色と文字サイズは HTML の `style` 属性を使うので、GitHub では表示されない。
- プレビューでのダブルクリックによる Mermaid のラベルの編集は、フローチャート、ER 図、状態図、クラス図、
  シーケンス図、円グラフ、ガントチャートだけ。構造化エディターは、再現できない構文を含む図は開かない。
- CSV のグリッドには、数式、数値と日付の書式、セルの結合、列のドラッグでの並べ替えが無い。
