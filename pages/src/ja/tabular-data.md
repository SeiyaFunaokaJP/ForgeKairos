# CSV と TSV のグリッド

[English](../tabular-data.md)

ForgeKairos は `.csv`、`.tsv`、`.psv`、`.ssv` を表計算ソフトのようなグリッドで開く
(`tabular_data.open_as_grid`)。元はファイルのテキストのままで、グリッドの操作はすべてテキストへの編集として
行い、1 回で取り消せる。保存、未保存の印、Git の差分、自動保存はふつうのテキストのファイルと同じに働く。

- グリッドのツールバーからテキストを横に開ける。テキストのエディターでは目のボタンでグリッドを開く。両方は
  同期する。Alt+クリックでタブをその場でグリッドとテキストに切り替える。
- 改行を含むセルは全部表示する (`tabular_data.multiline_cells`)。
- 「先頭行を見出し」は切れる。

## 編集

| キー | 操作 |
|---|---|
| Enter / Shift+Enter、Tab / Shift+Tab | 次・前のセルへ移る |
| 文字の入力 | セルの中身を置き換える |
| F2 かダブルクリック | セルをその場で編集する |
| Alt+Enter | セルの中で改行する |
| Delete | 中身を消す |
| Ctrl+Shift+= / Ctrl+- | 行か列を挿入・削除する |
| Shift+Space / Ctrl+Space | 行・列を選ぶ |
| Ctrl+D / Ctrl+R | 下へ・右へ埋める |
| Ctrl+F / Ctrl+H | 検索・置換 (正規表現と選択範囲の中も) |

- コピーは表計算ソフトが読めるタブ区切りの形式。
- 日本語入力などの IME をセルで使える。
- 空行は行として残し、元の引用符の付け方を保つ。

## 行と列

- 端に **+** の行と **列を追加** の列がある。行と列の境目の細い帯でその位置に挿入する。
- セル、行の見出し、列の見出しの右クリックのメニューで、挿入・削除・消去ができる。
- フィルハンドルは、1 つのセルからはコピーする (Ctrl を押すと数値は 1 ずつ増やす)。数値か日付 (曜日と
  日本語の日付の書き方を含む) が等差に並んだ 2 つ以上のセルからは、その並びを延ばす (Ctrl を押すとコピー)。
- 選択範囲の枠をドラッグするとセルを移し、Ctrl+ドラッグでコピーする。
- Ctrl+クリックで範囲を選択に足す。

## フィルター

列の見出しの ▾ (または Alt+Down) で、値の一覧か文字列で絞り込む: 含む、含まない、等しい、で始まる、で終わる、
空白、空白以外。1 列に 2 つまでの条件を AND か OR で組み合わせられる。フィルターと並べ替えはファイルごとに
覚える。

## セルの色

セル、行、列、表全体に、8 色の塗りと文字の色を付けられる。色はファイルではなく ForgeKairos が保存する。

## 比較

Git の HEAD の版、別のファイル、選んだセル・行・列どうしと比べられる。両側を並べ、セルと文字の違いを強調し、
どちらかが変われば比べ直す。複数行のセルは全体を比べる。

## 対応していないもの

数式、数値と日付の書式、セルの結合、列のドラッグでの並べ替えには対応していない。
